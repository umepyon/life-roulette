# 人生ルーレット

同じ画面で 2〜4 人が遊べる、オリジナルのブラウザ人生すごろくです。Nintendo のゲームや素材を使用しない独自実装です。

## 遊び方

1. 最初の画面で人数（2〜4人）と名前を入力します。
2. 順番にサイコロを振り、マスのイベントや分岐を楽しみます。
3. 全員がゴールした時点の手持ち資産が多い順で順位を決めます。

## 起動

依存関係はありません。`index.html` をブラウザで開くか、このフォルダで次を実行してください。

```bash
python3 -m http.server 4173
```

その後、[http://localhost:4173](http://localhost:4173) を開きます。

## ファイル

- `index.html` — 画面構造とアクセシブルなダイアログ
- `styles.css` — レスポンシブなゲーム画面デザイン
- `app.js` — 4人対戦、サイコロ、イベント、分岐、順位計算
