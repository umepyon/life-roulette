# 人生ルーレット

2〜4人が同じ画面または別々の端末で遊べる、オリジナルのブラウザ人生すごろくです。Nintendo のゲームや素材を使用しない独自実装です。男性8人・女性8人のアニメ調キャラクターから主人公を選び、ゲームごとに生成されるヘックス型の人生コースを進みます。結婚・子ども誕生イベントではオープンカーに乗る人形が増えます。

## 遊び方

1. 最初の画面で人数（2〜4人）とコースの大きさを決め、人物カードから主人公を選びます。名前は自由に変更できます。小コースは現在の遊び心地を保つ27マス、中コースは60マス、大コースは100マスです（いずれもSTARTからGOALまでのメインルート）。
2. 新しいゲームを始めると、選んだ大きさのシード付きヘックスコースと3つの2択分岐が生成されます。分岐は「就職・進学（大学へ進む／すぐに働く）」「結婚・家族（家族・結婚コース／仕事を優先）」「仕事・プロ（一般の仕事／プロを目指す）」の順に登場します。PCの盤面はアイコンだけで表示され、青いイベントマスと赤い分岐マスを見分けられます。止まったときに出来事カードまたは専用イベント画像で内容を確認します。
3. 入社、マイカー、マイホーム、宝くじ、修理費、副収入、結婚、赤ちゃん誕生、ゴールなどでは、その出来事専用のアニメ調イベント画像が表示されます。
4. 結婚・子ども誕生では、まだゴールしていないほかの参加者が順番にサイコロを振ってご祝儀を渡します（1万 / 2万 / 3万 / 5万 / 7万 / 10万円。4万円は使いません）。ゴール済みの人からは徴収しません。所持金はマイナスにもなります。
5. ゴールした人は全員、運命サイコロを振ります。出目1は「カジノで大損」で−1,000万円、出目2〜6は変化なしです。所持金がマイナスでゴールすると、男女別の節約暮らしエンディングになります。
6. ほかの全員がゴールした時点で、残った1人はビリとして自動的にゴールし、手持ち資産が多い順で順位を決めます。結果画面からゲームを終了することもできます。
7. コースには「3マスもどる」「1回休み」「先頭と入れ替え」が必ず入り、GOALの1つ手前は所持金が半分になってSTARTへ戻るマスです。
8. スマホ幅と横向きのスマホではタイトル説明を隠して、後方視点の四角いマス目の道をすぐに表示します。「みんなの人生」は折りたたみ式です。サイコロの目ぶん、車が1マスずつ進むパラパラ式アニメーションです。右上のメニューから新しいゲームとボード全体表示を選べます。iPad幅では見やすさを優先してPCボードを表示します。
9. iPhoneのノッチ／ホームインジケータを避ける余白、動きを減らすOS設定、44px以上の主要なタップ領域に対応しています。

## イベントCSV（管理者向け）

イベント内容は [data/events.csv](data/events.csv) で管理しています。ゲーム画面からの編集機能はありません。管理者がExcel・Numbers・テキストエディタなどでCSVを編集し、GitへコミットしてGitHub Pagesへ公開すると、次回のゲームから反映されます。

CSVには `id`、`type`、`label`、`sub`、`description`、`amount`、`icon`、`eventScene`、`weight`、`enabled` を指定します。通常イベント・給料や家賃収入などの収入・チャンスイベントを合計200件登録できます。大コースでも1ゲームで使うのは盤面にあるイベントマスだけで、残りは次のゲームの候補になります。

公開前には `node tests/event-catalog.test.js` で必須列、重複ID、金額、画像名、イベント種別を確認します。CSVが読み込めない場合は標準イベントへ戻るため、ローカルで `index.html` を直接開く場合はHTTPサーバーを使う公開時と挙動が異なることがあります。

## 別々の端末で遊ぶ（オンライン部屋）

1. ホストは「新しいゲーム」を開き、人数・コースの大きさ・名前・人物カードを設定してから「部屋をつくる」を押します。
2. 表示された8文字の部屋コードを、ほかの参加者に共有します。
3. 参加者は同じ公開URLを開き、「新しいゲーム」→「部屋に参加」を押して部屋コードを入力します。参加順に、ホストが設定した空きプレイヤーが割り当てられます。
4. 盤面、所持金、イベント、分岐、ご祝儀、ゴールは全端末で同期されます。各参加者は自分の番だけ操作できます。

部屋はホスト端末がゲーム進行を管理します。ホストがページを閉じたり再読み込みした場合は部屋が終了するため、新しい部屋を作ってください。

## 起動

ローカル対戦は依存関係なしで `index.html` を開いて遊べます。オンライン部屋は Supabase JavaScript を CDN から読み込むため、インターネットに接続した公開URLまたはローカルHTTPサーバーで開いてください。

```bash
python3 -m http.server 4173
```

その後、[http://localhost:4173](http://localhost:4173) を開きます。

## ファイル

- `index.html` — 画面構造とアクセシブルなダイアログ
- `styles.css` — レスポンシブなゲーム画面デザイン
- `app.js` — 4人対戦、サイコロ、イベント、3種類のテーマ分岐、順位計算
- `hex-course.js` — 新規ゲームで使う、シード付きヘックスコース生成・検証
- `event-catalog.js` — 管理者CSVの読み込み・検証・イベント候補への変換
- `online.js` — Supabase Realtimeの部屋コード、同期、操作権限
- `supabase-config.js` — 公開用Supabase URL・publishable key（secret key は置かない）
- `assets/` — オリジナルのアニメ調人物・イベント画像（イベント12場面）、スマホ用の後方視点オープンカー画像
- `data/events.csv` — 管理者が編集する200件のイベント定義
